# 景观设计需求转译与场地分析系统需求文档

## 1. 文档概述

### 1.1 文档目的

本文档用于描述当前项目的目标、用户、业务流程、功能范围、非功能要求和验收标准，并同步最新版本已经落地的能力。

### 1.2 当前版本定位

当前系统定位为“景观设计前期智能辅助工作台”，服务于课程展示、设计研究、前期策划和轻量方案辅助场景，不替代 CAD、BIM 或施工图工具。

## 2. 建设目标

### 2.1 总体目标

构建一个可运行、可演示、可归档的景观设计工作流平台，实现：

- 自然语言需求到数字化任务书的转换
- 场地描述到结构化分析报告的转换
- 规范知识库辅助检索与合规修正
- 相似案例推荐与参考案例沉淀

### 2.2 本轮优化目标

本轮重点优化如下：

- 优化界面显示稳定性，修复原始 HTML 片段外露问题
- 修复顶部布局遮挡问题
- 将数字化任务书保存到固定目录
- 增加本地相似案例推荐
- 增加在线案例检索、人工勾选和本地案例库入库能力
- 允许将已选案例同步写入数字化任务书

## 3. 目标用户

- 景观设计师
- 风景园林专业学生
- 教学展示使用者
- 研究项目成员
- 需要快速形成前期分析成果的轻量业务用户

## 4. 核心使用场景

### 4.1 需求转译

用户输入景观设计需求，系统结合规范知识库、语义映射和规则引擎，生成结构化任务书。

### 4.2 场地分析

用户上传场地资料或输入场地描述，系统输出结构化场地分析结果。

### 4.3 案例辅助决策

系统基于场地描述和分析结果推荐相似本地案例；用户也可主动检索在线案例，并将选中的结果导入本地案例库。

### 4.4 成果归档

系统自动保存数字化任务书、历史记录和案例选择结果，形成项目资产。

## 5. 功能需求

### 5.1 项目配置模块

功能要求：

- 支持输入项目名称
- 支持输入 API Key、Base URL、主模型、嵌入模型
- 支持调整规范检索条数
- 支持在侧边栏查看 Token 使用情况

当前状态：

- 已实现

### 5.2 知识库管理模块

功能要求：

- 支持上传 TXT、PDF、DOCX、DOC 文件
- 支持导入内置规范资源
- 支持文件预检查
- 支持文档切分、向量化、入库、去重
- 支持显示知识库状态与已登记文件清单

当前状态：

- 已实现

### 5.3 设计任务书模块

功能要求：

- 输入自然语言需求
- 检索规范片段并参与生成
- 输出结构化任务书 JSON
- 显示规则命中与风险提示
- 支持下载完整任务书档案
- 将数字化任务书固定保存到指定目录

当前状态：

- 已实现

### 5.4 场地分析模块

功能要求：

- 支持文件上传和文本输入
- 生成结构化场地分析结果
- 展示可信度与人工复核项
- 支持下载分析 JSON

当前状态：

- 已实现

### 5.5 本地案例推荐模块

功能要求：

- 基于场地文本和分析结果自动推荐相似项目
- 展示匹配度、推荐原因、亮点和匹配点
- 支持多选参考案例
- 已选案例可同步给任务书模块使用

当前状态：

- 已实现

### 5.6 在线案例检索与入库模块

功能要求：

- 支持输入检索词进行在线案例检索
- 支持展示标题、摘要、来源链接和匹配度
- 支持勾选在线案例
- 支持将勾选结果导入本地案例库
- 导入后可直接纳入当前任务书参考案例集合

当前状态：

- 已实现基础版本

说明：

- 当前版本采用轻量在线搜索方案，案例质量与检索词相关
- 当前为“结果级导入”，尚未做网页正文抽取与结构化摘要增强

### 5.7 项目历史与归档模块

功能要求：

- 按项目名称保留历史记录
- 展示输入摘要、运行时间、产物路径、输出预览
- 支持数字化任务书固定归档

当前状态：

- 已实现

## 6. 数据需求

### 6.1 核心输入

- API 配置参数
- 规范文件
- 场地资料
- 设计需求文本
- 案例检索词

### 6.2 核心输出

- 数字化任务书
- 场地分析报告
- 本地推荐案例列表
- 在线案例检索结果
- 历史归档记录

## 7. 非功能需求

### 7.1 易用性

- 页面流程清晰，支持课程展示与非技术人员操作
- 关键步骤应具备明显状态提示
- 错误提示应可理解且可恢复

### 7.2 可维护性

- 核心逻辑模块化放在 `src/landscape_workflow/`
- 规则、语义映射、案例库采用配置或资源文件管理
- 文档与测试应同步更新

### 7.3 可扩展性

- 支持继续扩展更多规范文件
- 支持继续扩展更多案例数据源
- 支持未来接入正文抽取、案例摘要、Word/PDF 报告导出

### 7.4 可靠性

- 数字化任务书应固定归档
- 知识库状态应可见
- 案例导入过程应避免重复入库

## 8. 当前不足

- 在线案例检索仍偏轻量，缺少网页正文抽取和质量评分
- 案例库仍以本地 JSON 为主，尚未形成完整后台管理能力
- 任务书输出虽然已支持参考案例，但尚未形成正式排版报告
- 结果差异化仍有提升空间，不同用户角色输入的区分度还不够强
- 当前仍主要依赖手动配置模型服务

## 9. 验收标准

- 能成功导入规范并构建知识库
- 能生成结构化任务书并保存到固定目录
- 能生成场地分析结果
- 能展示本地案例推荐
- 能完成在线案例检索、勾选和本地入库
- 能将选中案例写入数字化任务书结果
- 页面不存在原始 HTML 片段直接显示问题
- 顶部导航与内容区无重叠遮挡

## 10. 后续迭代建议

- 增加在线案例正文抓取与自动摘要
- 增加案例标签系统与人工编辑能力
- 增加 Word/PDF 模板导出
- 增加项目空间、版本管理和多方案对比
- 增加更精细的人群画像与角色化生成策略
