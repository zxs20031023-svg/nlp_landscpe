# 使用说明

## 1. 项目简介

本系统面向景观设计前期分析场景，支持以下核心任务：

- 规范知识库构建
- 景观设计需求转译
- 场地现状多维分析
- 相似项目推荐
- 在线案例检索与本地案例库入库
- 数字化任务书归档与历史记录管理

## 2. 环境准备

- Python 3.10 及以上
- 可用的 OpenAI Compatible API Key
- 可访问的模型服务地址

建议使用虚拟环境后再安装依赖。

## 3. 安装依赖

```bash
pip install -r requirements.txt
```

## 4. 启动项目

```bash
streamlit run app.py
```

默认访问地址通常为：

```text
http://localhost:8501
```

## 5. 首次配置

在左侧“项目控制台”中填写：

- `项目名称`
- `API Key`
- `Base URL`
- `主模型`
- `嵌入模型`
- `规范检索条数`

说明：

- `主模型` 用于任务书和场地分析生成
- `嵌入模型` 用于知识库向量化和检索
- `项目名称` 会影响历史记录和任务书文件命名

## 6. 功能使用流程

### 6.1 知识库管理

推荐优先完成这一步。

操作方式：

1. 进入“知识库管理”
2. 点击“导入内置规范”或上传规范文件
3. 如有需要，先点击“预检查文件”
4. 点击“构建或更新知识库”

支持格式：

- `.txt`
- `.pdf`
- `.docx`
- `.doc`

说明：

- 系统优先推荐使用 `DOCX/TXT`
- 扫描版 PDF 会尝试 OCR 或使用预处理兜底资源

### 6.2 场地分析

操作方式：

1. 进入“场地分析”
2. 上传场地资料，或直接输入场地描述
3. 点击“生成场地分析报告”
4. 查看结构化结果、规则命中和可信度提示

系统会自动在页面下方输出：

- 本地相似项目推荐
- 在线案例检索入口

### 6.3 在线案例检索与入库

操作方式：

1. 在“场地分析”页底部输入检索词
2. 点击“检索在线案例”
3. 勾选感兴趣的在线案例
4. 点击“导入所选在线案例到案例库”

导入后：

- 案例会写入本地案例库
- 会自动进入当前参考项目集合
- 可以继续同步到数字化任务书

建议检索词写法：

- `深圳 社区口袋公园 适老 儿童活动`
- `老旧社区 微更新 景观案例`
- `滨水 康养 步道 景观案例`

### 6.4 数字化任务书生成

操作方式：

1. 进入“设计任务书”
2. 输入设计需求
3. 确认已选中的参考项目
4. 点击“生成数字化任务书”

输出包含：

- 结构化任务书
- 规范检索依据
- 规则命中结果
- 已同步参考案例
- 风险与修正提示

### 6.5 历史记录查看

进入“项目历史”后，可查看：

- 历史运行记录
- 输入摘要
- 归档路径
- 输出预览

## 7. 文件归档位置

重要目录如下：

- 向量库：`runtime/chroma_db/`
- 历史记录：`runtime/output_briefs/`
- 数字化任务书：`runtime/output_briefs/digital_briefs/`
- 本地案例库：`resources/reference_projects/project_case_library.json`

## 8. 常见问题

### 8.1 未填写 API Key

现象：

- 点击按钮后无法生成结果

处理：

- 在左侧先填写可用的 `API Key`

### 8.2 知识库尚未就绪

现象：

- 任务书生成时报知识库未准备完成

处理：

- 先进入“知识库管理”导入规范文件

### 8.3 上传 PDF 后解析失败

可能原因：

- 文件是扫描版
- 文本层为空

处理：

- 尽量使用 `DOCX/TXT`
- 或先进行 OCR 再上传

### 8.4 在线案例检索结果不理想

原因：

- 在线搜索依赖检索词质量

处理：

- 优先使用“城市 + 场地类型 + 主题词”的组合
- 如结果不稳定，可先导入本地案例再使用

## 9. 建议使用顺序

1. 填写模型参数
2. 构建知识库
3. 生成场地分析
4. 选择推荐项目或在线导入案例
5. 生成数字化任务书
6. 查看归档结果和历史记录
